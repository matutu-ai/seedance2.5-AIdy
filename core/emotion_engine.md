# Emotion Timeline Engine

Build a causal emotional arc so a character does not hold one expression for the whole clip.

## Timeline contract

For a 12-second scene, use this adaptable structure:

```text
0–3 seconds — initial state: baseline emotion, attention target, restrained behavior
3–6 seconds — escalation: external trigger and first physical response
6–9 seconds — peak reaction: strongest but believable expression/action
9–12 seconds — resolution: choice, recovery, concealment, or unresolved hold
```

Scale the timestamps to the requested duration. Every phase needs a trigger, an inner shift, and at least one visible change. Keep a single continuous arc for a single take; use cuts only when the story needs them.

## Arc patterns

- Fear: vigilance → alert → recoil/freeze → controlled resolve.
- Grief: composure → recognition → breath break/tears → acceptance or restraint.
- Anger: stillness → jaw/eye tension → decisive movement → contained aftermath.
- Wonder: attention → slowed breath → widening focus → quiet approach.
