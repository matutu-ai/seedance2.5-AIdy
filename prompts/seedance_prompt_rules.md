# Seedance Prompt Rules

Always state Commercial TVC, 15s/30s/60s duration, 16:9, camera/lens/movement, lighting/color/texture, identity/emotion/action, hero product/material/detail, music/voice-over, continuity, and no AI artifact / unnatural movement / random character change. Chinese is the default output language; separate the director analysis from one copy-ready final prompt and label assumptions.
