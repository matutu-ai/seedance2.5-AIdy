# Emotion Library

## Design an arc

Map emotion as `baseline → stimulus → involuntary reaction → chosen response`. Prefer changing intensity, attention, or control over switching to an unrelated emotion.

| Arc | Timing cue | Useful visual behavior |
|---|---|---|
| Suspense | sound or unseen movement | scan → hold breath → recoil → advance |
| Reunion | recognition of a loved one | disbelief → breath catches → touch → quiet embrace |
| Desire | object comes within reach | attention narrows → hand slows → contact → release |
| Confidence | obstacle is accepted | measured inhale → eye lock → decisive step |
| Shame | attention turns toward the character | gaze drops → shoulders close → delayed glance back |

For dialogue, leave a pause for listening. For silent filmic scenes, let eyes, breath, and hands carry the inner turn.
