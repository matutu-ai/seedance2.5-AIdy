# Lighting Language

| Term | Meaning | Directing use |
|---|---|---|
| Key/main light | dominant shaping source | name source, direction, softness |
| Fill | shadow-side illumination | define contrast, or deliberately omit |
| Back/rim light | source behind subject | separation from dark background |
| Practical | visible in-scene lamp/source | motivates light and depth |
| Motivated light | believable source outside/inside frame | protects continuity |
| Hard light | sharp shadows, defined edges | tension, noon sun, noir |
| Soft light | broad transition, gentle shadow | intimacy, beauty, overcast |
| Color temperature | warm/cool color balance | emotional and time-of-day logic |

Specify light movement only when a subject, camera, or source actually changes position. “Warm key from screen left, cool cyan practical in deep background” is more useful than “high-end lighting.”
