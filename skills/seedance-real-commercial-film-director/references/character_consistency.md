# Character Consistency Reference

Use a stable `CHARACTER_ID` and repeat the identity block across shots. Identity contains face, age impression, hair, body proportions, wardrobe, shoes, and accessories. Motion contains gaze, expression, breath, weight transfer, hand contact, and settling behavior.

Do not let a reference pose become a permanent pose. Do not let an action rewrite facial structure, clothing, or age. If the reference does not show a feature, mark it unknown and choose a conservative framing.

High-risk checks: face drift, outfit changes, accessory loss, extra fingers, hand-object intersection, mirrored screen direction, and incompatible lighting on the same take.
