# Venue Multi-View Reference

Build a landmark graph from wide, left, right, stage, and audience views. Store each landmark's relative position, adjacency, orientation, and confidence. Reuse the graph for every shot.

When two images disagree, prefer the view with clearer boundaries and state the uncertainty. Never invent a second stage, move an entrance, reverse seating, or change the camera side merely to make a composition easier.

Useful anchors include entrance, stage edge, presentation screen, podium, first seating row, aisle, window, column, and lighting rig.
