# Character Lock Workflow

Split identity from motion. Write identity once, then describe only shot-specific behavior on the timeline.

## Identity layer

```text
CHARACTER_ID: unique label
Face: stable facial structure and distinguishing features
Age impression, hair, body proportions
Wardrobe, shoes, accessories, colors and materials
Reference coverage: what is visible and what remains unknown
```

## Motion layer

```text
Attention / gaze target
Expression and micro-expression
Breathing and weight transfer
Hands and object contact
Body movement and clothing response
Trigger → action → settling state
```

Use minimum-sufficient dynamics: a chest-up portrait does not need gait or foot placement; a product hand interaction does not need full facial anatomy. For a turn, use `eyes first → torso/weight → head → hair/clothing delay → settle` when that chain is visible.

## Failure guards

Lock face, wardrobe, and accessories across every shot. Prohibit face merge, identity swap, clothing swap, extra fingers, hand intersection, and motion disconnected from the stated body mechanics.
