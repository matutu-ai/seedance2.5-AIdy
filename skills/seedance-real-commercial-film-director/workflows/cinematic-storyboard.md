# Commercial Cinematic Storyboard Workflow

Design a readable commercial arc before polishing shots. The default 30-second structure is a scaffold, not a rule for every brief.

| Time | Dramatic function | Visual requirement |
|---|---|---|
| 0–8s | problem / hook | begin inside an observable action; establish the human need |
| 8–20s | learning / transformation | show a credible process, relationship, or product value |
| 20–30s | result / brand moment | resolve the action and hold a legible final state |

For each beat define `SHOT`, `ACTION`, `CAMERA`, `LIGHT`, and `AUDIO`. Use one primary camera movement per shot: dolly in, arc move, push in, tracking, crane, or focus pull. A cut can change the shot; it must not erase venue or character continuity.

## Storyboard table

```text
Shot N | time | purpose | character state | venue anchors | camera | light | audio | end state
```

Keep the first frame active, create a visible change by the end of the beat, and reserve the final 1–2 seconds for a natural brand or human resolution.
