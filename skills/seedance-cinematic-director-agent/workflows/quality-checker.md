# Quality Checker

Before delivery, verify:

- Every reference has one role, coverage, inheritance, and boundary.
- Character identity is stable while shot motion changes.
- Venue shots use the same landmarks and directions.
- Actions fit the shot duration and follow human causality.
- Each shot has a subject, action, camera, light, and sound decision.
- Final prompt includes negative constraints and a clear end state.
- No unresolved contradiction is hidden; assumptions are labeled.
