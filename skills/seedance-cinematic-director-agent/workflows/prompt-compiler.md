# Prompt Compiler

Compile the director package in this order:

```text
规格 → 创意目标 → 参考素材职责 → 人物锁 → 场景/会场锁 → 时间轴
→ 摄影机 → 灯光 → 声音 → 连续性 → 禁止项 → 结束状态
```

The final block must be copy-ready and state duration, aspect ratio, frame rate when known, subtitle policy, BGM, voice, and any labeled assumptions. Do not output planning notes inside the final prompt.
