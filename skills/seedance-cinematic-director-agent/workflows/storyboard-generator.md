# Storyboard Generator

Use a commercial arc appropriate to the requested duration. For a 30-second default:

| Time | Function | Required fields |
|---|---|---|
| 0-8s | problem / hook | SHOT, ACTION, CAMERA, LIGHT, AUDIO |
| 8-20s | learning / transformation | SHOT, ACTION, CAMERA, LIGHT, AUDIO |
| 20-30s | result / brand moment | SHOT, ACTION, CAMERA, LIGHT, AUDIO |

Use one dominant camera movement per shot. A cut may change framing, but cannot erase character or venue continuity. End on a stable brand state with readable product or message placement.
