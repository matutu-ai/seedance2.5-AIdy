# Character Lock Engine

Build two blocks:

```text
IDENTITY: face, age impression, hair, body proportions, wardrobe, persistent accessories
MOTION: gaze, expression, hands, weight transfer, posture, clothing and hair response
```

Identity is loaded into every shot. Motion is loaded only into the shot where it occurs. Keep facial asymmetry, eye direction, hand ownership, and wardrobe continuity explicit. Describe human action causally: attention -> eyes -> weight -> torso/limbs -> head -> hair/clothing -> settle.
