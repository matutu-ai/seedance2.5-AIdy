# Venue Memory Engine

Convert multi-view venue images into one landmark graph. Record each landmark's relative position, adjacency, orientation, and confidence.

Required anchors when visible: entrance, stage edge, presentation screen, podium, first seating row, aisle, window, column, and lighting rig. Every venue shot should cite at least two anchors. Preserve entrance direction, stage position, seating order, building proportions, and screen direction across cuts.
