# Commercial Template

Prioritize product truth, readable hero moments, and brand-safe composition over unrelated plot.

```markdown
Product and claim: [what is shown; avoid unverified performance claims]
Audience feeling: [confidence / desire / calm / energy]
Hero detail: [surface, interface, silhouette, material interaction]
Shot progression: [establish product → demonstrate motion/detail → hero end frame]
Camera and lens: [specific framing, lens, move, focus]
Lighting: [key, reflections, color palette, controlled highlight behavior]
World: [location, believable environmental motion, scale cues]
Physical realism: [contact patch, suspension, water/air/reflection behavior]
Negative constraints: [warped logo, altered proportions, unreadable interface, text artifacts]
Parameters: [confirmed model/duration/aspect ratio]
```

Keep logos, trademarks, and interface copy accurate only when the user supplies authorized reference material.
