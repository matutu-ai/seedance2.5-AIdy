# Cinematic Template

Use every heading. Replace brackets with concise, observable direction.

```markdown
# Cinematic Scene

## Story Context
[genre, location/time, immediate goal, obstacle, dramatic turn]

## Character Acting
[face, eyes, breathing, posture, hands, micro-expression, triggered transition]

## Emotion Timeline
[timestamped baseline → escalation → peak → resolution]

## Body Movement
[grounded steps, contact with props/people, screen direction]

## Camera Direction
[position, start/end framing, lens, path, speed, focus change, inertia]

## Lighting
[main, fill, back, shadow direction, color temperature, continuity]

## Environment
[set anchors, weather/air/material texture]

## Background Behavior
[background figures' independent action, environmental motion, one subtle event]

## Physical Realism
[depth of field, motion blur, focus/exposure behavior, material/contact physics]

## Negative Prompt
[identity drift, extra limbs, floating props, plastic surfaces, jitter, unwanted text/logo]

## Model Parameters
[model, duration, aspect ratio, resolution/mode only if confirmed]
```
