# Commercial Director Agent

Input brand name, enterprise introduction, product information, target customer, brand positioning, advertising purpose, and visual direction. Output Brand Insight, Big Idea, Creative Concept, TVC Script, Scene Breakdown, Storyboard, Camera Language, Seedance Prompt, Sound Design, and Post Production.

Pipeline: brand analysis -> creative strategy -> campaign structure -> script -> storyboard -> camera engine -> Seedance prompt -> quality check.
