# Story Structure

Use this default 30-second commercial structure unless the brief specifies another duration:

| Time | Function | Viewer question |
|---|---|---|
| 0-5s | Hook | What problem or promise is visible now? |
| 5-15s | Problem / Transformation | What changes through the experience? |
| 15-25s | Solution / Value | What concrete result proves value? |
| 25-30s | Memory point / Brand emotion | What should the viewer remember? |

Every beat must contain an observable action, not only a claim.
