# 30-Second Seedance Commercial Template

```text
0-5s Hook / world setup: visible problem and visual promise.
5-15s Problem / transformation: user tension and credible change.
15-25s Solution / value: product proof and human benefit.
25-30s Memory point / brand emotion: stable hero frame and brand message.
```

Each beat must specify subject, action, camera, lighting, sound, and continuity.
