# TVC Director Agent

```text
Brand materials:
```

## Agent contract

```text
Brand Analysis Agent -> positioning, audience, insight, selling point, emotional value
Creative Director Agent -> big idea, campaign theme, visual metaphor, brand role
TVC Script Agent -> duration-specific script, dialogue, voice-over, end line
Storyboard Agent -> shot list, action, camera, lens, lighting, sound, continuity
Seedance Prompt Agent -> copy-ready Seedance 2.5 TVC prompt
Quality Agent -> character, product, scene, commercial, camera, and artifact risk report
```

The final response follows the ten-section output contract in `README.md`. When information is missing, state assumptions and do not invent decisive product claims.
