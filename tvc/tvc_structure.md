# TVC Structure

## 15 seconds

```text
0-3s visual hook → 3-8s conflict / need → 8-12s product value → 12-15s brand memory
```

## 30 seconds

```text
0-5s world setup → 5-15s user pain → 15-25s product solution → 25-30s brand elevation
```

## 60 seconds

```text
Opening → Problem → Emotion → Solution → Product Hero Shot → Brand Message → Logo Ending
```
