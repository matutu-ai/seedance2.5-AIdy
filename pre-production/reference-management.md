# Reference Management

Assign each image a role and boundary:

```text
@Image1 ROLE: CHARACTER_IDENTITY
Controls: face, age, hairstyle, body
Does not control: background, lighting, pose

@Image2 ROLE: SCENE_REFERENCE
Controls: environment, composition, architecture

@Image3 ROLE: STYLE_REFERENCE
Controls: color, atmosphere, visual language
```

Never blend all images into an undifferentiated instruction. A style image must not overwrite identity or venue geometry.
